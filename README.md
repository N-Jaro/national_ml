# Multimodal Multitask Deep Learning for Hydrographic Feature Delineation

This repository contains the source code and experimental results for a project focused on the delineation of hydrographic features using a multimodal, multitask deep learning approach. The model, **MDMT_v1**, is designed to leverage diverse data sources to accurately identify and map water bodies such as rivers and streams. This work utilizes satellite imagery and other geospatial data, processed in patches for efficient training and inference.

---

## Key Features

* **Multimodal Data Integration:** The model is built to process and learn from multiple types of data simultaneously, such as optical satellite imagery and digital elevation models, to create a more comprehensive understanding of the landscape.
* **Multitask Learning Framework:** By training the model on several related tasks concurrently, such as identifying different types of water features (e.g., rivers, lakes), the overall performance and generalization capabilities of the model are improved.
* **Patch-Based Processing:** To handle large-scale geospatial data, the project employs a patch-based approach, breaking down larger areas into smaller, manageable tiles for model training and prediction.
* **Experiment Tracking with Weights & Biases:** All experiments are logged and visualized using Weights & Biases, allowing for robust monitoring and comparison of different model versions and training runs.

---

## Dataset

The project utilizes data patches generated via Google Earth Engine, as indicated by the `gee_patches_output.ipynb` notebook. The raw data is processed into a structured format suitable for training the deep learning model. The `data` directory is organized as follows:

* `data/raw`: Contains the initial, unprocessed data patches.
* `data/processed`: Holds the cleaned and preprocessed data ready for the model.
* `data/meta`: Includes any metadata associated with the datasets.

---

## Project Structure

The repository is organized to separate concerns, making it easier to navigate and contribute.

* `src/`: Contains the core source code for the project.
    * `models/`: Defines the neural network architectures, including **mdmt_v1.py**.
    * `preprocess/`: Includes scripts for data preprocessing.
    * `training/`: Contains the scripts for training the models.
    * `utils/`: Provides utility functions used across the project.
* `notebooks/`: A collection of Jupyter notebooks for data exploration, visualization, and patch processing.
    * `gee_patches_output.ipynb`: Notebook for generating data patches from Google Earth Engine.
    * `exploration.ipynb`: For initial data analysis and understanding.
    * `patch_visualization.ipynb`: Tools for visualizing the data patches.
* `experiments/`: Configuration files and scripts for running different experiments.
* `outputs/`: Stores the outputs generated by the model, such as prediction maps and evaluation metrics.
* `wandb/`: Contains files related to Weights & Biases logging.

## Installation

To get started with this project, clone the repository and install the required dependencies.

```bash
git clone [https://github.com/your-username/national_ml.git](https://github.com/your-username/national_ml.git)
cd national_ml
pip install -r requirements.txt
```

It is also recommended to set up the environment using the `environment.yml` file for conda environments.

```bash
conda env create -f environment.yml
conda activate national_ml
```

## Usage

**Data Preprocessing**

To process the raw data, you can run the preprocessing scripts located in the `src/preprocess` directory.

**Training the Model**

To train the `mdmt_v1` model, execute the main training script. Ensure your `wandb_settings.yaml` is configured with your Weights & Biases account to log the experiments.

```bash
python src/training/train_model.py
```

**Running Experiments**

The experiments directory contains scripts and configurations for running various experimental setups.

## Model Architecture

The core of this project is the Multimodal Multitask (MDMT) v1 model, defined in `src/models/mdmt_v1.py`. This model is a deep neural network designed to accept multiple data modalities as input. It features a shared backbone to learn common representations from the different data sources. The network then splits into multiple heads, with each head dedicated to a specific hydrographic delineation task. This architecture allows the model to learn rich, generalized features that benefit all tasks, leading to more accurate and robust predictions.
